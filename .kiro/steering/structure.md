# Structure

- `src/core` state, audio, assets, settings, rng, events
- `src/scenes` gate and rooms
- `src/interactions` one module per interaction
- `src/ui` warning modal, settings panel, HUD
- `src/styles` theme.css, fx.css, fonts.css
- `src/a11y` reducedMotion, focus
- `tests/unit` Vitest tests
- `public/assets` images, audio, placeholders, manifest.json
- `scripts` asset collection and verification
